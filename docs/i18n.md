# Internationalization

Breeze fully supports internationalization. See [docs/i18n/](i18n/) for the complete documentation.

Quick links:
- [Architecture reference](i18n/ARCHITECTURE.md): component map, locale lifecycle
- [Adding a language](i18n/adding-a-language.md): step-by-step runbook
- [Translator guide](i18n/translator-guide.md): editing XLIFF files

**Source locale:** `en` (US English content, neutral BCP-47 tag)  
**Launch locale:** `fr` (French)  
**Frontend:** `@lit/localize` v0.12.2 (runtime mode)  
**Backend:** `nicksnyder/go-i18n/v2` v2.6.1 (TOML messages)  
**Formatting:** native `Intl.*` APIs (no date-fns/dayjs)

To add a new locale, see [adding-a-language.md](i18n/adding-a-language.md).
