# Types

## Location

`src/types/` is currently a placeholder (only `.gitkeep`). Shared UI types
live in `src/api/types.gen.ts` and feature-local `types.ts` files.

## What belongs here

- Route parameter shapes
- Custom event payload types
- Store shape interfaces (not generated)
- Theme name unions

## What does NOT belong here

Generated API types live in `src/api/types.gen.ts` (auto-generated by
`@hey-api/openapi-ts`). Do not duplicate them.

## Rules

- Only types that are specific to the UI layer.
- No generated types; those go in `src/api/types.gen.ts`.
- No business-logic types from the domain; those are defined in Go and mirrored
  in the generated SDK.
